# Original scientific exploration reading (#148)

This continuation completes portable reading for the bounded scientific routes
already exposed by the initial exploration adapters: experimental structures,
canonical-region questions and source/area knowledge coverage. Broader scientific
profiles, full machine conformance, measured costs and researcher acceptance stay
open. The 0.15.0 consolidation pause remains in effect; this is development code.

## One public reading route, two retained formats

`CardView.save`, `AccessSelection.save` and `sabueso.read_exploration` keep their
existing signatures. Literal-only bundles retain `sabueso.card_exploration@1` and
`literal_exploration_binding@1`. Scientific closures use the additive, distinct
`sabueso.card_exploration@2` format and `scientific_exploration_binding@1` verifier.
The reader supports both. The original literal producer's frozen synthetic bytes
remain readable; a newer scientific format never changes the meaning of @1.

Format @2 adds `scientific_results`, binding each retained structural wire result
to its original focal capture. It keeps original native results, all underlying
rows, selected/display-filtered rows, exclusions, source/qualifier conflicts,
unknowns, scoped explanations, effective options, question requests and finite
navigation history. Resolution cells, native inventory/detail/explanation rows
and physical equality predicates use PyUnitWizard QuantityRecord with explicit
`relationships.has_structure.resolution`/`angstrom` expectations. They are not
bare numbers or values interpreted through the reader's session defaults.

Machine selections retain their original `XA_`, projection and effective options.
Only exact retained variants can be selected again; missing projections/options
return `not_saved`. Paging still enforces record/byte bounds and issues local
cursors. Following a supplied-capture destination restores that focal capture's
retained requests without exposing another focal result's item registry.
Human topic/question lookup reuses original variants; it never materializes an
unvisited scientific question. Missing canonical prerequisites and unsupported
sequence axes retain their original explicit outcomes.

## Historical consistency, separate from a new interpretation

The reader never constructs a Card, calls ordinary scientific readers, queries
sources, follows a store's latest pin or substitutes current classification rules.
Original output is restored through an inert versioned result/transport adapter.
`start_new()` remains the explicit way to use installed readers over those same
captures; it leaves the original saved interpretation unchanged.

The historical verifier checks original decision consistency with frozen expected-
record predicates for:

- `structure_inventory@1`, `structure_state@2` and `structure_coverage_class@1`;
- `structure_inventory_explanation@1`, including excluded and uninventoried items;
- `knowledge_state@5` and `knowledge_state_explanation@2`, including original
  selected/alternative support, reported versus unknown counts, request failures,
  missing subsets, source context and actual classification inputs;
- the original canonical-region prerequisite decision and structural scope.

The private `card_exploration_*_v1` modules contain historical comparison predicates
and the initial declarative source/area catalog. Their expected records are never
returned or stored as replacement knowledge. No second public scientific producer
is introduced. Current live readers remain authoritative for new interpretations.
New scientific or catalog semantics require a new verifier/version; changing v1
to make a newer producer pass would destroy the historical contract. Future
ordinary reader/default/column changes do not redefine a retained v1 result.

Expected derivations distinguish generated rule metadata from original source
records; only the original producer SDK label is recorded rather than independently
verified. Original source bodies are compared unchanged. Declared result quantities
are compared physically with their required field/unit binding; literal lookalikes
never gain quantity semantics. The verifier refuses coherently rebound scientific
decisions inconsistent with the captured inputs, separately from checking hashes.

`view.validation` reports the rules actually checked. Internal integrity, original
support binding and historical decision consistency do not establish source
authenticity or scientific truth. An independently retained `expected_digest`
additionally binds the caller's exact original bundle. Missing required members,
foreign focal inputs, invalid quantities or unavailable required verifiers are
`StorageError`; atomic publication still preserves an existing output on failure.

## Preserve the original coverage evaluation

Coverage captures retain the original knowledge-state output, classification-input
frames, count-field catalog and explanation factory when the view is materialized.
Scoped explanations remain lazy and cached. Preparing their closure uses those
original inputs rather than rerunning knowledge-state classification or consulting
the current catalog. Ordinary `Card.explain_knowledge_state` keeps its current
behavior; the captured-input path is private to exploration.

Saving prepares support only for materialized results and their originating trail.
It does not derive every topic or recursively open every source node. Required
root/ancestor closure cannot silently downgrade; optional unretained operations
stay `not_saved`. Source response archives, article bodies, acquisition/runtime
sidecars and external provenance stores remain outside this bundle. Retained
references do not become new access or attribution credit.

## Qualification and remaining acceptance

The selected human/access/argument, structural/state, quantity and diagnostic
suites pass 509 cases with twelve pytest-receptor workers and fatal runtime,
SQLite/unraisable guards. Tests include independent readers with current scientific
entry points/catalogs/columns forbidden or changed, original quantities under a
nondefault policy, explicit region failures, source gaps/exclusions/conflicts,
focal isolation, exact saved requests and rehashed/rebound tampering. Final full
source and publication receipts belong to #148.

Measure canonical bytes, save/read time, memory and capture/materialization cost
before claiming economical storage or scaling. Complete support/navigation closure
can be much larger than a visible table; bounded machine pages are a separate
transport contract. Continue machine selector/support conformance, source-preview
roles, ontology labels and researcher walkthroughs. Remote qualification follows
the [deferred exact-head route](deferred_ci.md); no release is selected here.
